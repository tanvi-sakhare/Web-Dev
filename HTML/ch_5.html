Inline and Block elements

HTML elements are generally divided into two categories: Block-level and Inline elements.

Inline Elements don't start on a new line. It only takes the width required to cover the content. Inline elements can contain other inline elements, but they generally should not contain block-level elements. Example: Span Tag

Block-level elements are those that start on a new line and take up the entire width of their container by default. They essentially claim all the horizontal space for themselves, pushing any content that comes after them to a new line.Characteristics: Width and height can be controlled via CSS. Can contain other block-level as well as inline elements. Example: Div Tag (division tag).
