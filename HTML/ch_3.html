Tags covered = Images, Lists, and tables

1. Image Tag

The image tag is used to embed or display an image on a webpage. It uses the src attribute to specify the image file (basically a link of the image) and the alt attribute to provide alternative text (for instance if the image becomes unavailable for some reason the user will at least get a reference or context about the image).Example:

Sports Car

Also height and width can be set according to us with using attributes like width and height in the img tag itself. If any one of the two is set by us the other will be set or adjusted accordingly. Using attribute the same image looks like, where height is set to 100(pixels):

Sports Car

While using the width and height attribute we only need to add a number in the inverted commas as the number will be received in context of pixels by default.

2. List Tag

List tags are used to organize and display related items in a list format. There are three types of lists which HTML supports:- 1.Unordered lists, 2.Ordered Lists, and 3.Definition lists. The items are listed using li tag which stands for list items.

a. Unordered Lists - ul

Example:
  • Apple
  • Mango
  • Watermelon
The 'type' attribute is used to customize the bullet points in unordered list. It supports three values: Disc(by default), Square, and Circle.

b. Ordered Lists - ol

Example:
  1. Apple
  2. Mango
  3. Watermelon
The 'type' attribute supports 5 values in ordered list. Which are as follows(type="_"):
I for Uppercase Roman
i for Lowercase Roman
1 for Arabic Numerals (by default)
a for Lowercase Alphabetical
A for Uppercase Alphabetical

c. Definition Lists - dl

Fruits
Apple
Mango
Watermelon

3. Table Tag

Table tags are used to display data in rows and columns. The main tags are: table- creates the table, tr- table row, th- table header (used for headings), and td- table data (basically a cell).
Example of a Table:

Sr No. Name Roll No.
1. ABC 001
2. XYZ 002
